Canonical API contract

Built for Open.

The commercial contract is Analysis; the canonical authenticated API namespace belongs to open.onerall.com. That keeps benchmark UX separate from infrastructure while sharing one identity and billing system.

GET https://open.onerall.com/v1/analysis/models
GET https://open.onerall.com/v1/analysis/providers
GET https://open.onerall.com/v1/analysis/benchmarks
GET https://open.onerall.com/v1/analysis/models/{id}/history

Authorization: Bearer onr_...

These routes define the target public contract for the authenticated Analysis API. The current public benchmark feed remains available separately on analysis.onerall.com.
